# My-First-Python-Project
My first Python project created while learning Python.
Student Marks & Result System 🐍

About the Project

This is my beginner-level Python project. It takes a student's name and marks in Maths, English, and Hindi as input.

Features

- Takes student name as input
- Accepts marks in three subjects
- Calculates total marks
- Calculates percentage
- Displays Pass or Fail result

Technologies Used

- Python

Learning Outcome

Through this project, I practiced Python input, variables, arithmetic operations, and if-else statements.
